# Frontend

Angular 21 standalone app with Spotify OAuth (PKCE) integration.

For full setup and run instructions, see the [root README](../README.md).

## Quick Start

> Must be served on `127.0.0.1:5173` for Spotify OAuth to work.

```bash
npm install
ng serve --host 127.0.0.1 --port 5173
```

## Scripts

| Command | Description |
|---------|-------------|
| `ng serve --host 127.0.0.1 --port 5173` | Start dev server |
| `ng build` | Production build |
| `ng test` | Run unit tests (Vitest) |
